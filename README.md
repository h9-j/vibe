# myenv_vibe

게임과 웹사이트 기획·실험 작업을 모아 둔 프로젝트입니다.

- `brick/`: BRICK SHIFT 웹 게임. 실행 방법은 [`brick/README.md`](brick/README.md)를 참고하세요.
- `sites/`: 웹사이트 기획 문서. 배포 빌드와 생성된 체크아웃은 저장소에서 제외합니다.
- `font/`: 프로젝트에서 사용한 폰트 파일.
- `pyproject.toml`, `uv.lock`, `.python-version`: Python 환경과 의존성 정보.

로컬 환경 변수는 `.env`에 보관하고 저장소에 올리지 않습니다.
