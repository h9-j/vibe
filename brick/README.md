# BRICK SHIFT

기획서 기반 HTML5 Canvas 벽돌 깨기 게임입니다. 5개 월드에 일반 스테이지 3개와 보스전 1개씩, 총 20개 구역이 있습니다. 각 월드의 배경은 생성한 일러스트를 사용합니다. 별도 패키지 설치가 필요하지 않습니다.

## 실행

`brick` 폴더에서 다음 명령을 실행한 뒤 `http://localhost:8765`를 엽니다.

```powershell
python -m http.server 8765
```

## 조작

| 기능 | 조작 |
|---|---|
| 패들 이동 | 마우스, A/D, ←/→ |
| 발사·퍼펙트 리시브 | 클릭, Space |
| 속성 전환 | 1/2/3, Q/E |
| 필살기 | X, 우클릭 |
| 일시정지 | Esc, P |

터치 화면에는 화면 아래에 조작 버튼이 표시됩니다. 월드를 클리어하면 다음 월드가 열립니다. 최고 점수와 월드 해금은 브라우저에 저장됩니다.

## 확인

```powershell
& 'C:\Program Files\nodejs\node.exe' .\smoke.cjs
```

메뉴, 게임 루프, 렌더링, 속성 전환, 카드 선택, 20개 구역의 진행, 이동 벽돌과 보스 패턴을 점검합니다.
