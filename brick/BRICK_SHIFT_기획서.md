# BRICK SHIFT — 게임 기획서

> **한 줄 콘셉트:** 속성을 갈아 끼우고, 날씨를 무기로 삼는 네온 벽돌 깨기.
> **장르:** 아케이드 · 벽돌 깨기 · 로그라이트 빌드
> **플랫폼:** 웹 (HTML5 Canvas, 마우스/키보드)
> **문서 버전:** v0.2 / 2026-11-20

---

## 0. 원안 대비 변경 요약

| 원안 | 처리 | 내용 |
|---|---|---|
| 공 진화 (멀티/관통/파워) | **유지 + 확장** | 카드 선택 방식의 로그라이트 빌드로 확장 (§4) |
| 특수 벽돌 (폭탄/철갑/보너스) | **유지 + 확장** | 속성·날씨와 상호작용하는 벽돌 12종 (§6) |
| 콤보 | **유지 + 역할 추가** | 점수 배수 + **필살기 게이지 충전원** (§7) |
| 스테이지별 기믹 | **변경** | 스테이지 → **월드(5개)** 단위, 월드마다 날씨·벽돌·보스 고정 (§8) |
| 네온 디자인/잔상/파티클 | **유지** | 월드별 테마 팔레트 추가 (§11) |
| 목숨 3개 / 최고 기록 | **유지** | 쉴드, 퍼펙트 리시브 추가 |
| (없음) | **신규** | 속성 전환(Shift), 날씨 시스템, 패들 프레임, 필살기, 보스 공격, 미션 |

**이름의 의미 (SHIFT):** 공 속성 전환 + 날씨 전환 + 월드 전환. 이 3가지가 게임 정체성이다.

## 1. 디자인 필러 (모든 결정의 기준)

1. **읽히는 혼돈** — 화면이 화려해도 공·패들·위험 요소는 항상 한눈에 보인다.
2. **선택이 결과를 바꾼다** — 속성, 카드, 프레임 선택이 실제로 플레이를 다르게 만든다.
3. **날씨는 장식이 아니라 규칙** — 모든 날씨는 게임플레이 효과를 가진다. 효과 없는 날씨는 넣지 않는다.
4. **짧고 강한 한 판** — 월드 1회 플레이 10~12분, 실패해도 바로 재도전.

---

## 2. 핵심 루프

```
[프레임 선택] → [월드 입장]
   → [스테이지 플레이: 공 튕기기 + 속성 전환 + 날씨 대응]
        → 벽돌 파괴 → 진화 게이지 → [카드 3택1]
        → 콤보 → 필살기 게이지 → [필살기 발동]
   → 스테이지 3개 클리어 → [보스전] → [월드 클리어 보상/해금]
```

- **1스테이지:** 2~3분
- **1월드:** 일반 3 + 보스 1 = 약 10~12분
- **카드 빌드는 월드 단위로 초기화** (캠페인 전체 유지 시 밸런스 붕괴 위험이 커서 월드 = 1판으로 설계)

## 3. 속성 시스템 — ELEMENT SHIFT (핵심 차별점)

공은 3가지 속성 중 하나를 가진다. 플레이 중 언제든 전환 가능 (쿨다운 1.5초).

| 속성 | 색 / 아이콘 | 기본 효과 | 강한 대상 | 약한 대상 |
|---|---|---|---|---|
| **FIRE** | 오렌지 / 둥근 불꽃 | 타격 시 화상(2초간 지속 피해), 얼음 벽돌 즉시 파괴 | 얼음·눈 쌓인 벽돌 | 용암(면역), 젖은 벽돌(화력 감소) |
| **ICE** | 시안 / 육각 결정 | 타격 시 둔화·동결(벽돌 이동 정지, 보호막 타이머 정지) | 용암·이동 벽돌 | 얼음 벽돌(면역) |
| **VOLT** | 노랑 / 지그재그 | 타격 시 인접 벽돌로 체인 (기본 2칸) | 금속·전도체 벽돌 | 고무 벽돌(절연) |

- **상성:** 약점 속성 데미지 ×2, 저항·면역 ×0.5 / ×0
- 공 색, 잔상, 파티클이 속성별로 완전히 달라짐 (색 + **모양**으로 구분 → 색약 대응)
- 전환 시 짧은 변신 연출 (0.2초 링 이펙트, 공 일시 확대)
- **전환 쿨다운이 있는 이유:** 무한 전환 시 선택의 의미가 사라진다.

## 4. 공 진화 시스템 (카드)

벽돌을 부수면 **진화 게이지**가 찬다 (일반 +1, 보너스 벽돌 +3). 가득 차면 **시간이 느려지며(0.1배속)** 카드 3장이 제시되고 1장 선택.

- 필요량: 1차 20 → 2차 35 → 3차 55 → 이후 +20씩
- 슬롯 최대 5개, 같은 카드를 다시 고르면 레벨업 (최대 Lv3)
- 스테이지당 리롤 1회
- 희귀도: 일반(C) / 희귀(R) / 에픽(E)

| 카드 | 희귀도 | Lv1 | Lv2 | Lv3 |
|---|---|---|---|---|
| 멀티볼 | C | 공 +1 | 공 +2 | 공 +3 |
| 관통 | C | 2개 관통 | 4개 | 6개 |
| 파워 | C | 데미지 +1 | +2 | +3 |
| 폭발 | C | 인접 1칸 피해 | 반경 확대 | 연쇄 폭발 |
| 유도 | R | 약한 유도 | 중간 | 강한 유도 |
| 분열 | R | 벽돌 파괴 시 20% 소형 공 | 35% | 50% |
| 자석 캐치 | R | 패들에 붙음 + 조준 발사 | 조준선 길어짐 | 붙어 있는 동안 게이지 충전 |
| 헤비 볼 | R | 속도 -15%, 데미지 +1 | -25%, +2 | -35%, +3 |
| 속성 증폭 | R | 현재 속성 효과 +30% | +60% | +100% |
| 위기 탈출 | E | 낙하 시 1회 바운스 | 스테이지당 2회 | 3회 |
| 중력 렌즈 | E | 공이 근처 벽돌 쪽으로 휨 | 범위 증가 | 범위 최대 |
| 이중 속성 | E | 공이 2속성 동시 적용 (전환 시 교체) | 쿨다운 -30% | 쿨다운 없음 |

**시너지 예시:** 관통 + VOLT = 관통하며 체인 / 멀티볼 + 분열 = 화면 폭주 / 헤비 볼 + 폭발 = 느리지만 강한 한 방

## 5. 패들 시스템

### 5-1. 기본 규칙
- 패들 위치에 따라 반사각이 달라짐 (가장자리일수록 각이 큼)
- **퍼펙트 리시브:** 공이 닿기 직전 0.1초 안에 클릭하면 공 속도 +10%, 다음 타격 데미지 +1, 필살기 게이지 +5, 'PERFECT' 연출. 실패해도 페널티는 없다 (성공 시 보상만).
- 패들이 공을 놓치지 않는 한 콤보 유지

### 5-2. 프레임 (패들 캐릭터) — 월드 입장 전 선택

| 프레임 | 컨셉 | 패시브 | 필살기 |
|---|---|---|---|
| **STRIKER** (기본) | 균형형 | 퍼펙트 리시브 판정 +50% | **OVERDRIVE** — 8초간 모든 공 관통 + 속도 ×1.3 |
| **GUARDIAN** (해금) | 수비형 | 패들 +25% 넓음, 바닥 쉴드 1회 자동 충전 | **BARRIER** — 15초간 바닥 전체 보호막 (공이 떨어지지 않음) |
| **CASTER** (해금) | 공격형 | 자석 캐치 기본 내장, 조준선 표시 | **METEOR** — 상단에서 유성 10발 낙하 (범위 폭발) |

### 5-3. 아이템으로 변하는 패들 (임시, 15초)
와이드 / 슬림(데미지 +) / 레이저(패들에서 발사) / 자석 / 쉴드(바닥 1회)

## 7. 콤보 & 필살기

### 7-1. 콤보
- **공이 패들에 닿기 전까지** 연속으로 벽돌을 부수면 콤보 +1 (공마다 별도가 아닌 **전체 합산**)
- 패들에 닿으면 콤보 **유지하되 타이머 3초**, 이 시간 안에 다시 파괴 못 하면 초기화 (패들이 닿자마자 리셋되면 너무 가혹함)

| 콤보 | 배수 | 연출 |
|---|---|---|
| 0~4 | ×1 | — |
| 5~9 | ×2 | NICE — 텍스트 팝, 가벼운 화면 진동 |
| 10~19 | ×3 | GREAT — 배경 펄스, 파티클 증가 |
| 20~34 | ×4 | **FEVER** — 배경 색 전환, BGM 레이어 추가, 공 잔상 길어짐 |
| 35+ | ×5 | **OVERLOAD** — 화면 가장자리 네온 라인, 히트스톱 강화 |

### 7-2. 필살기 게이지
- 충전: 벽돌 파괴 +1 / 콤보 단계 도달 시 +10 / 퍼펙트 리시브 +5 / 오로라 날씨 중 ×1.5
- 100% 도달 시 패들이 빛나며 **필살기 버튼 활성화**
- 발동 시: 0.3초 컷인(프레임 이름 + 일러스트 대신 네온 실루엣) → 화면 슬로모션 → 효과 → 종료
- 한 스테이지당 평균 1~2회 사용되도록 충전량 조정

## 9. 날씨 시스템 — LIVE WEATHER

스테이지 내에서 **스케줄에 따라 날씨가 전환**된다. 전환 3초 전에 상단에 **전조 아이콘 + 카운트다운**을 표시한다. (불공정한 랜덤 방지)

| 날씨 | 시각 연출 | 게임플레이 효과 | 속성 연계 |
|---|---|---|---|
| **맑음** | 별빛, 약한 네온 글로우 | 효과 없음 (휴식) | — |
| **비** | 빗줄기 파티클, 바닥 물결·네온 반사 | 모든 벽돌 '젖음', 패들 이동 약간 부드러워짐 | VOLT 체인 범위 ×2 / FIRE 폭발 반경 -30% |
| **눈** | 눈송이, 벽돌 위 눈 쌓임 | 패들 **미끄러짐(관성)** | ICE 둔화 효과 +50% / FIRE가 눈을 녹이며 주변 벽돌에 약한 피해 |
| **폭풍** | 번개 플래시, 구름, 빠른 비 | **번개:** 무작위 벽돌에 낙뢰 (0.8초 전 표시) → 대전 상태(VOLT 피해 ×2) / **바람:** 공 궤적 약간 휨 (방향 화살표 표시) | VOLT 강화 |
| **안개** | 화면 하단에서 올라오는 안개 | 일부 벽돌의 HP·속성 숨김 | VOLT 공이 지나가면 일시 스캔 |
| **화산재** | 회색 재 파티클, 붉은 하늘 | **유성 낙하:** 패들 위로 떨어지는 용암 파편 회피 필요 (맞으면 패들 0.5초 경직) | FIRE 강화 / ICE 효과 증가 |
| **유성우** | 사선으로 떨어지는 별 | 유성이 벽돌에 직접 낙하 (플레이어에게 유리) | — |
| **오로라** | 상단 커튼형 빛 | **보상 날씨:** 아이템 드롭률 ×2, 필살기 충전 ×1.5 | — |

- 날씨 지속 20~30초, 사이에 맑음 5~8초 휴식
- 설정에서 **날씨 이펙트 강도(끔/약/보통/강)** 조절 가능 (효과 자체는 유지, 시각 효과만 줄임)

## 10. 보스전

일반 스테이지와 달리 **보스는 공격을 한다.** (패들 회피 요소 추가로 긴장감 확보)

| 보스 | 패턴 | 약점 |
|---|---|---|
| **GATE KEEPER** (W1) | 4초 ON / 3초 OFF 보호막 (원안 반영), 상단 포탑 2개가 레이저 탄 발사 | 보호막 OFF 시 코어 / 포탑 파괴 시 코어 노출 시간 증가 |
| **ICE GOLEM** (W2) | 얼음 탄 낙하 — 맞으면 패들 1.5초 동결 / 팔 벽돌 재생 | FIRE, 얼음 팔 파괴 후 코어 |
| **THUNDER BIRD** (W3) | 낙뢰 전조 패턴 (격자 라인), 날개 벽돌이 공 반사 | VOLT 면역 → FIRE/ICE로 공략 |
| **MAGMA CORE** (W4) | 용암 기둥 / 용암 벽돌 소환 | ICE로 용암 굳히기 후 파괴 |
| **VOID HEART** (W5) | 3페이즈: ①벽돌 소환 ②중력 우물(공 휨) ③속성 순환(3초마다 약점 속성이 바뀜) | 페이즈별 속성 약점 |

- 보스 HP 바 상단 표시, 페이즈 전환 시 화면 연출
- 모든 공격은 **0.8초 이상 전조 표시**

## 11. 미션 시스템

### 11-1. 스테이지 미션 (★ 3개)
| 별 | 조건 |
|---|---|

## 16. 기술 설계 (구현용)

- **스택:** 순수 HTML + JavaScript(ES Modules) + Canvas 2D, 외부 라이브러리 없음
- **논리 해상도:** 960×720, 화면 크기에 맞춰 스케일
- **루프:** 고정 타임스텝 (1/120초 서브스텝) + 렌더 requestAnimationFrame
- **충돌:** 원(공) vs 사각형(벽돌/패들), 이동량이 큰 경우 서브스텝으로 터널링 방지
- **오브젝트 풀:** 파티클 상한 800, 총알/유성 풀링
- **저장:** `localStorage` — 최고 기록, 별, 해금 상태, 설정, 데일리 미션
- **데이터 중심 설계:** 스테이지·카드·벽돌·날씨는 데이터 파일로 분리 (코드 수정 없이 추가 가능)

### 폴더 구조 (제안)
```
/src
  main.js          게임 루프
  core/            input, audio, storage, scale
  game/            ball, paddle, brick, collision, combo, ultimate
  systems/         element, weather, cards, drops, boss, mission
  data/            stages.js, bricks.js, cards.js, weather.js, frames.js
  ui/              hud, menu, cardPicker, gameOver
  fx/              particles, shake, hitstop, trail
```

### 스테이지 데이터 예시

## 19. 열린 결정 사항 (구현 전 확인 필요)

1. 캠페인 진행 방식: 월드 단위 초기화(현재 안) vs 전체 유지 — 전자가 밸런스 쉬움
2. 속성 전환 쿨다운: 1.5초(현재 안) — 플레이 테스트로 조정
3. 필살기를 프레임별로 분리할지, 초기에는 1종 공통으로 시작할지 — **초기엔 1종 공통을 권장**
4. 벽돌 하강 모드(주기적으로 한 줄씩 내려옴)는 엔드리스 모드 전용으로 보류
