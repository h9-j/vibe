# CLAUDE — Game PO 자기소개 사이트 통합 기획서

## 목적과 대상

가상 인물 클로드의 배경, 일하는 방식, 성향과 목표를 한 페이지에서 보여준다. 방문자는 첫 화면에서 이름·직무·핵심 관점을 파악하고, 카드 탐색을 통해 더 자세한 이야기를 읽는다. 주요 대상은 부트캠프 동료와 포트폴리오 방문자다.

## 콘텐츠 원칙

- `claude_persona.md`를 인물 설정의 기준으로 삼는다. NEXUS GAMES와 PROJECT NOVA는 가상이다.
- 성과 수치, 사례, 입사 연도, 연락처를 새로 지어내지 않는다.
- ENTJ 지표를 보여줄 때는 창작 설정값이며 실제 검사 결과가 아님을 가까이 표기한다.
- 사이트 하단에 가상 인물 기반 포트폴리오임을 명시한다.

## 디자인 방향

- 네이비·아이보리·블루를 사용하되, 사진 없이 타이포그래피와 도형으로 인물을 표현한다.
- 첨부 레퍼런스의 핵심인 **기울어진 카드, 겹침, 회전, 이동**을 첫 화면의 카드 덱과 본문의 카드에 적용한다.
- 자동 모션은 느리고 제한적으로 사용한다. 포인터·클릭·키보드 조작으로 직접 카드를 탐색할 수 있게 한다.
- 모바일은 카드 겹침을 줄여 읽기 쉽게 하고, 모션 최소화 설정을 존중한다.

## 정보 구조

1. **Hero:** 이름, Game Product Owner, 핵심 메시지, 움직이는 카드 덱.
2. **About:** 전략 게임에서 출발한 관심, 컴퓨터공학 배경, 현재 역할.
3. **Work:** PROJECT NOVA의 PO 업무와 판단 기준. 가상 프로젝트임을 표기.
4. **Personality:** ENTJ 설정, 장점과 성장 과제, 창작 지표.
5. **Beyond Work:** 게임·운동·음악·영화·독서·주말 취향.
6. **Vision:** 단기·장기 목표와 재미/성과, 속도/협업의 균형.

## 상호작용

- 카드 덱: 이전/다음 버튼, 키보드 좌우 방향키, 포인터 드래그, 카드 클릭. 활성 카드는 전면으로 회전·이동한다.
- 섹션 카드: 호버·포커스 시 절제된 기울기와 상승.
- 내비게이션: 앵커 이동 및 현재 섹션 표시.
- 화면 진입 효과: 한 번만 재생하고, `prefers-reduced-motion`에서는 제거.

## 구현 및 검증

정적 HTML/CSS/JS로 구현한다. 모바일·데스크톱 레이아웃, 키보드 탐색, 대비와 터치 영역, 모션 최소화 설정을 확인한다. 실제 수신처가 정해지기 전까지 연락 버튼과 더미 링크는 넣지 않는다.

## 두 기획서에서 조정한 사항

| 항목 | 결정 | 이유 |
|---|---|---|
| 컬러 | 네이비·아이보리·블루 | 두 기획서의 공통 방향이며 레퍼런스의 선명한 대비와 맞음 |
| 섹션 | 중복 내용은 6개 흐름으로 압축 | 페이지 길이와 정보 반복 감소 |
| 연락처 | 제외 | 더미 주소·`#` 링크의 오작동과 오해 방지 |
| 성과·사례 | 추가하지 않음 | 페르소나에 근거가 없음 |
| 비주얼 | 모노그램·타이포 카드 | 가상 인물의 가짜 사진 사용 방지 |
| 모션 | 카드 덱을 중심으로 집중 | 첨부 이미지의 인상 반영, 과도한 동작 억제 |
