# CLAUDE — 자기소개 사이트 통합 기획서 (v2)

## 목표
가상 게임 PO 클로드를 강한 첫인상과 짧은 문장으로 소개한다. 방문자는 인물, 직무, 사고방식, 목표를 한 페이지에서 파악한다.

## 시각 방향
- 흰색과 검은색을 기본으로, 코발트 블루를 강조선과 일부 타이포그래피·카드에만 사용한다.
- 첫 화면은 대형 타이포그래피와 새로 생성한 가상 인물 사진으로 구성한다. 참고 사진의 화보 분위기를 활용하되 인물은 별도로 창작한다.
- 첫 화면 아래에 회전·이동하는 카드 덱을 배치한다.
- 모든 글꼴은 사용자 제공 Paperlogy를 사용한다. 본문 400, 부제목 500, 제목 700, 대형 영문 900.
- 문구는 짧게 유지하고 내용이 겹치는 섹션은 합친다.

## 페이지 구성
1. Hero: 클로드, Game PO, “전략을 실행으로.”
2. 카드 덱: Identity / Project NOVA / Mindset / Next. 클릭·드래그·버튼·키보드로 탐색.
3. About: 게임에 대한 관심과 현재 업무를 두 문장으로 설명.
4. Work · Off Duty · Next: 일, 취향, 목표를 각 한 카드로 요약.
5. Closing: 다음 질문과 가상 인물 고지.

## 사실과 표현
- 인물은 창작한 가상 인물이다. NEXUS GAMES와 PROJECT NOVA도 가상 설정이다.
- 제공된 페르소나에 없는 성과 수치, 사례, 연락처는 만들지 않는다.
- 모바일 가로 넘침을 방지하고, 키보드 탐색과 모션 최소화 설정을 지원한다.

## 두 원안에서 남긴 요소
- 단일 페이지 구조, 게임 PO 중심 스토리, 인터랙티브 카드, 가상 설정 고지.
- 네이비·아이보리 기반의 긴 섹션과 성격 수치 그래프는 최신 디자인 요청에 맞춰 제거했다.
